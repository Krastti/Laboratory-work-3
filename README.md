# Laboratory-work-3

## Build

```bash
cmake -S . -B build
cmake --build build
```

Базовый интерфейс:

```bash
cmake --build build --target LaboratoryWork3
```

Пример работы с кватернионами и СЛАУ:

```bash
cmake --build build --target LaboratoryWork3Example
```

Unit Tests:

```bash
cmake --build build --target LaboratoryWork3Tests
```
