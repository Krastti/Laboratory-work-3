# Laboratory-work-3

## Build

### Windows

```powershell
cmake -S . -B build
cmake --build build
```

Unit Tests:

```powershell
cmake --build build --target LaboratoryWork3Tests
```

### Linux / macOS

```bash
cmake -S . -B build
cmake --build build
```

Unit Tests:

```bash
cmake --build build --target LaboratoryWork3Tests
```
